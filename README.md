# 글로벌 AI 전략 로드맵 대시보드

## 프로젝트 개요
이 프로젝트는 주요 국가들의 AI 동향과 과학기술정보통신부의 AI 관련 협약 및 액션을 한눈에 파악할 수 있도록 구축된 인터랙티브 웹 지도입니다. 사내에 구축된 AI 전략 로드맵 파일의 세부 데이터를 기반으로 핵심 관계망을 시각화했습니다.

## 주요 기능
* **글로벌 AI 네트워크 시각화:** 대한민국을 중심으로 주요 AI 강국 및 협력국 간의 관계망 표시
* **과기정통부 액션 연동:** 국가별 과기정통부의 주요 협력/MOU 내역 요약과 공식 보도자료 URL 제공
* **실시간 동향 업데이트:** 구글 뉴스 RSS를 활용한 국가별 최신 실시간 AI 뉴스 크롤링
* **클린 UI 기반 리포트:** CartoDB Positron 타일을 적용하여 비즈니스 환경에 적합한 깔끔한 대시보드 팝업 구현

## 실행 방법
1. **패키지 설치:** 터미널에서 `pip install -r requirements.txt` 실행
2. **데이터 세팅:** 사내 문서인 **AI 전략 로드맵** 파일의 최신 내용을 `app.py` 내부의 딕셔너리(`countries_data`)에 업데이트
3. **스크립트 실행:** 터미널에서 `python app.py` 실행
4. **결과물 확인:** 생성된 `outputs/ai_roadmap_clean.html` 파일을 웹 브라우저에서 열람
